## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| keyboard / clipboard -> capture <textarea> | Keystrokes, paste, drop, IME composition, and `isTrusted === false` synthetic events enter the capture surface |
| capture logs -> Session -> (Phase 3 / Phase 4) | The keystroke log + char log is a verbatim transcript of everything typed, including anything pasted-then-retyped |
| host response headers -> browser | COOP/COEP on the HTML document is what the degraded-timing banner reports on |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-04 | Tampering (data integrity) | src/capture/capture.ts | low | mitigate | `isTrusted === false` events rejected in both the keydown/keyup and the beforeinput handlers (extensions / automation) |
| T-01-03 | Information disclosure | src/capture/capture.ts, src/session.ts | high | mitigate | The keystroke + char logs are memory-only (D-02); no `fetch` / `sendBeacon` / WebSocket anywhere in `src/`; README states the transcript never leaves the machine; Phase 4 persistence (deferred) is constrained to local IndexedDB only |
| T-01-08 | Tampering (answer leakage / timing corruption) | src/capture/capture.ts, src/ui/CaptureSurface.tsx | medium | mitigate | Paste and drop into the typing surface are cancelled via selective `preventDefault` on `beforeinput` and flagged inline; corpus-box paste (INPUT-01) is deliberately unaffected |
| T-01-09 | Denial of Service (wedged key after alt-tab) | src/capture/capture.ts | low | mitigate | `downCodes.clear()` on `blur` and `visibilitychange->hidden`; markers recorded so Phase 2 can bound active time |
| T-01-05 | Elevation of privilege (Spectre surface) | README.md guidance | medium | mitigate | README's isolation guidance keeps deployers on COOP/COEP with self-hosted assets; no third-party runtime scripts added |

# Phase 9 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope of this phase's UI (per 09-CONTEXT.md D-01..D-21 + 09-RESEARCH.md):** GitHub TS/JS
> files type **in place** as a scaffolded exercise. New `FileScaffold` paints the full file in
> **source order**: done (canonical static), current (`CaptureSurface` on the unit slice only),
> future (`text-muted` static). Landmark **N / M** + kind/name. Immediate start on file click;
> instant advance; Escape and Restart reset the **current unit** only. Last unit → existing
> `ResultsView` + one History row. Paste/upload stay whole-file `CaptureSurface` (no FileScaffold).
> Fallback one-unit still FileScaffold; PLAN-03 notice stays in the RepoBrowser status region.
>
> **This EXTENDS `01-UI-SPEC.md` through `07-UI-SPEC.md`.** All spacing / typography / color
> tokens below are inherited unchanged. **This phase introduces zero new color tokens and
> zero new type roles.** Reuse `src/index.css` (`.text-label`, `.text-muted`, `.control`,
> `.primary`, `.trainer-stack`, `--color-text`, `--color-text-muted`, `--color-surface`,
> `--color-border`, `--space-*`). Out of scope: cloze, Monaco, syntax highlight, `innerHTML`,
> whole-file restart control, per-unit WPM, changing CaptureSurface props or overlay contract.

## Design System

**Primary focal point:** the current unit's CaptureSurface caret — same as Phase 2. FileScaffold
orients the eye with the landmark and a secondary-surface **current card** in document order;
done/future text is context, not the typing target.

| Property | Value |
|----------|-------|
| Tool | none — unchanged from Phase 1–7 (hand-rolled CSS custom properties in `src/index.css`). shadcn gate: `components.json` is absent; prior phases already declined a library; COEP `require-corp` still forbids third-party asset hosts; 09-RESEARCH.md installs no packages. `--auto`: not re-asked. |
| Preset | not applicable |
| Component library | none — native `<pre>` / `<p>` / `<div>` / `<button>` plus existing `CaptureSurface` |
| Icon library | none — no unit-kind icons, no chevrons, no file-type glyphs |
| Font | Inherited unchanged: `var(--font-mono)` from `01-UI-SPEC.md`. No new font role. |

**No new packages this phase** (09-RESEARCH.md Standard Stack). Do not add shadcn, a highlighter, a virtualizer, or icon packs.

**Product identity (unchanged):** keyboard-centric developer tool — monospace-forward, terminal-adjacent, calm. Theme follows `prefers-color-scheme` with no manual toggle.

## Spacing Scale

Inherited unchanged from `01-UI-SPEC.md` (multiples of 4 only): `--space-xs` 4px, `--space-sm` 8px, `--space-md` 16px, `--space-lg` 24px, `--space-xl` 32px, `--space-2xl` 48px, `--space-3xl` 64px.

**Layout — page / header / corpus shell:** unchanged from `07-UI-SPEC.md`. Header stays three siblings (Trainer | History | Analytics). Paste | GitHub tabs, RepoBrowser tree, and CorpusInput geometry stay as Phase 7/8. `--column-max: 45rem` is not widened.

**Layout — FileScaffold (new this phase, D-01..D-06, D-13):**

Stacked grid in the existing trainer subtree (hide-not-unmount, `display: none`, never `hidden`):

1. **Landmark** — above the file chrome, **outside** the scroll container so **N / M** stays visible while the file scrolls. `display: grid; gap: var(--space-xs)`. `margin: 0`. Reserved `min-height: 1.4em` on the **N / M** line (same WR-05 floor as captions). Optional kind/name subtitle on the next line; no extra reserved slot beyond content height.
2. **File chrome** — one scroll container (see overflow exception) holding source-order **segments** (`gap` then `unit`) with **`gap: 0`**. Segments are states, not three stacked curriculum-order blocks: sort by `PlanUnit.start`; classify done / current / future from curriculum `unitIndex`. Inter-unit trivia is a **gap** segment (static, canonical, not muted-as-future, not typeable).
3. **Current unit card** — the current segment only. Secondary surface + 1px `--color-border` + `border-radius: 6px` (same treatment as `.preview` / `.results-panel`). Contains existing `CaptureSurface` unchanged (label **Type here**, 8-row overlay, keystroke count, paste-block). Do not add a second caption on the card.
4. **Done / future / gap `<pre>`** — no card chrome, no extra margin between segments. Padding `var(--space-md)` on every `<pre>` **and** the current card so glyph columns share the same inset as `.trainer-stack`. `margin: 0`. `white-space: pre-wrap`; `overflow-wrap: anywhere`; `tab-size: 4` — match CaptureSurface overlay metrics, **not** `.preview`'s `white-space: pre` / no-wrap.

**Layout — App around FileScaffold:**

- GitHub scaffold in progress: `FileScaffold` → (optional) `ResultsView` / `SaveFailedNotice` after last unit → Restart button while in progress.
- Paste/upload: **no** `FileScaffold`. `CaptureSurface` on full `exercise.text` as today. Gap trainer ↔ Restart remains `--space-md`.
- Restart sits **below** FileScaffold (or CaptureSurface), **outside** the file-chrome scroll, so it stays reachable without scrolling the file.

**Visual focal point:** while scaffolding, the current-unit card (caret inside CaptureSurface). After last-unit persist, the existing results panel is the focal point; file chrome becomes all-done static context.

### Spacing exceptions

| Exception | Value | Rationale |
|-----------|-------|-----------|
| File chrome overflow | `max-height: 70vh; overflow: auto` on the chrome wrapper | Taller than `.repo-tree` / `.preview` (`40vh`) because this **is** the trainer, not a browse panel. Caps a ~100 KB file so Restart and results are not pushed off-screen. Horizontal scroll only if a single unbreakable token still overflows after wrap. |
| Landmark **N / M** reserved height | `min-height: 1.4em` | Same WR-05 caption floor; one line. Kind/name may wrap below and grow the landmark. |
| Segment stack gap | `0` | Source-order file; blank lines live in gap slices of `Exercise.text`, not in CSS gap (09-RESEARCH.md Pitfall 4). |
| Current card vs static `<pre>` padding | `var(--space-md)` (16px) all segments | Aligns with `.trainer-stack` padding so done/future glyphs line up with the overlay. |
| CaptureSurface `rows={8}` | unchanged | D-05: do not teach CaptureSurface new props. Small units still sit in the existing 8-row host — accepted this phase. |

No 44px exception for Restart — it stays on the global control floor. Tree 32px exception is unchanged (Phase 7).

## Typography

Inherited unchanged from `01-UI-SPEC.md` — reused, not redeclared. **Zero new sizes, zero new weights** (2-weight discipline 400/600 maintained):

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 15px | 400 | 1.5 |
| Label | 13px | 600 | 1.4 |
| Heading | 20px | 600 | 1.3 |
| Display | 28px | 600 | 1.2 |

- **Landmark `N / M`:** Label role (13/600/1.4), color `--color-text`.
- **Landmark kind/name subtitle:** Body 15/400/1.5, class `text-muted`.
- **Done / gap static source:** Body 15/400/1.5, color `--color-text`. Reuse `glyphFor` for space (`·`) and newline (`↵`) at the **same font-size** as surrounding text; mute via existing `.ws-glyph` opacity `0.55`, not a smaller size.
- **Future static source:** Body 15/400/1.5, class `text-muted`, same `glyphFor` / `.ws-glyph` rules. Do not further reduce size.
- **Current unit:** CaptureSurface overlay contract unchanged (Body 15/400/1.5 on both stacked layers; per-status colors from `02-UI-SPEC.md`).
- **Restart unit / Restart exercise:** Body 15px, weight **600** (existing `.primary`).
- **Empty-state heading:** Heading 20/600/1.3 — **No exercise loaded** (unchanged).
- **Empty-state body:** Body 15/400/1.5, `text-muted`.

Display (28px) is **not** used inside FileScaffold. No italic. No letter-spacing adjustments.

Long identifiers in the landmark subtitle and long lines in static `<pre>` wrap with `overflow-wrap: anywhere`. **No ellipsis.**

| Secondary (30%) | `--color-surface` (`#efeeec` / `#161b22`) | **Current-unit card** fill only (plus existing inputs, selected tabs, results) |

| — accent text-on | `--color-accent-text-on` | Label on Restart / Load / Import primary fill |
| Destructive | `--color-destructive` | **Not used by FileScaffold.** RepoBrowser / CorpusInput errors unchanged. |

**Current-unit highlight (locked — no new token):** `--color-surface` fill + `--color-border` stroke. Weight 600 is reserved for the landmark **N / M** and primary buttons, not for painting source text. The typing signal remains the focused textarea border + accent caret (Phase 2). Do **not** paint the current card with `--color-accent`. Do **not** add a left-accent bar.

**Done vs future vs gap:**

| Segment role | Text | Surface | Typeable |
|--------------|------|---------|----------|
| done | `--color-text` | none (page bg) | no |
| gap | `--color-text` (canonical trivia, **not** muted-as-future) | none | no |
| current | CaptureSurface per-status (`correct` / `pending` / `incorrect`) | `--color-surface` card | yes — slice only |
| future | `--color-text-muted` | none | no |

After last-unit persist, every source segment uses the **done** row (canonical `--color-text`, no textarea).

**Accent reserved for (explicit, exhaustive — Phase 9 additions in bold):**

1. Primary buttons (“Load exercise”, “Restart exercise”, **“Restart unit”**, “Import”) — solid accent fill. Only one Restart label is visible at a time (paste vs scaffold).
2. The focus ring on every interactive element — unchanged (2px accent outline, `outline-offset: 2px`). Never removed.
3. The capture `<textarea>` border while focused — unchanged.
4. The custom trainer caret — unchanged.

Accent is **never** used for: landmark numerals, current-unit card fill/stroke, done/future source, kind/name, empty-state, or decorative file chrome.

Whitespace glyphs in static regions follow Phase 2: status/parent color dimmed in place via `.ws-glyph` opacity. Future text is already muted; glyphs stay `.ws-glyph` on top of that — do not invent a third gray.

## Interaction Contract

### Click-to-type (D-07..D-11)

- Clicking a loadable TS/JS file **starts typing immediately** on curriculum unit 0. No Start button, no plan-preview, no extra confirm.
- App `onPlanned={startScaffold}`. **Never** `handleLoad(plan.exercise)` for GitHub.
- Fallback (`plan.fallback === true`, one whole-file unit) still starts immediately and still mounts FileScaffold. The existing RepoBrowser fallback notice stays in the tree status region.
- Last-wins: a new GitHub file click replaces an in-progress scaffold (discard unit snapshots, `resetCapture`, remount at unit 0). Paste/upload `handleLoad` clears curriculum and mounts whole-file CaptureSurface (no FileScaffold).
- Switching Paste | GitHub tabs does **not** reset (Phase 7 D-04). Hide-not-unmount of the trainer subtree is unchanged. The tree stays browseable while typing.

### File chrome (D-01..D-06)

- Render segments in **source order** (`start` ascending), including gap slices so SCAF-01 “full file visible” is true. Curriculum order is typing order only.
- Done / future / gap: React text children (or `glyphFor` spans) only. **No** `innerHTML`, `dangerouslySetInnerHTML`, markdown, or highlighter. A fixture `'<img src=x onerror=alert(1)>'` must appear as characters.
- Future and done are **not** `<textarea>`. `user-select: text` on static regions. Clicks on static text do not type and do not steal focus into CaptureSurface (selection is allowed).
- CaptureSurface `text` is the current unit's `Array.from` slice only. For `units.length > 1` that string is never the full file.
- CaptureSurface props stay `{ text, onRestartRequested, onComplete }`. Do not pass `FilePlan`, GitHub, or `unitIndex`.

### Unit advance (D-12..D-15)

- Completing the current unit **instantly** advances: snapshot capture logs → `resetCapture()` → bump `loadToken` → remount CaptureSurface on the next slice. No interstitial, no Next button.
- Landmark updates to the new **N / M** (and kind/name) in the same turn. `aria-live="polite"` `aria-atomic="true"` `role="status"` on the landmark.
- `useLayoutEffect` on `unitIndex` (and initial mount): current-card `scrollIntoView({ block: 'nearest', inline: 'nearest', behavior })` with reduced-motion branch above. Default `block: 'start'` is forbidden (yanks under the header).
- Do **not** call persist `onComplete` until the **last** unit. Fallback 1-unit: first complete **is** last.

### Last unit + results (D-14, Pitfall 11)

- Last unit complete → existing `ResultsView` + fire-and-forget `saveSession`. One Session per file; History github `sourceRef` (`owner/repo:path`) becomes UAT-checkable.
- After persist: FileScaffold remains, **all segments done static** (CaptureSurface unmounted), Restart **hidden**. Do not arm a second `saveSession` from Escape/Restart. Retry = click the file again or paste/upload.

### Restart (D-16..D-18)

- Escape (CaptureSurface, trusted keydown only) **and** the Restart button share one handler.
- Scaffold in progress: restart **current unit only**. Do not zero `unitIndex`. Do not drop completed snapshots. Do not refresh file-level `startedAt`. Remount the same slice (`loadToken++`, `resetCapture`).
- Paste/upload: today's whole-session Restart (`Restart exercise`), including a new `startedAt`.
- **No** whole-file restart control on the scaffold path.

### Keyboard

- Tab inside CaptureSurface remains fully absorbed (Phase 2). Escape is the keyboard path to Restart unit.
- Tab order with FileScaffold mounted: corpus tabs → GitHub/paste controls → (tree if GitHub tab) → capture textarea → Restart unit (when visible). Static file text is not tab stops.
- Landmark is not focusable.

### Motion

- No new CSS animation. `scrollIntoView` smooth vs instant is the only new motion. Cap existing control transitions at `--motion-duration` (150ms) under `prefers-reduced-motion: no-preference`.
- No unit-complete flash, no spinner, no celebratory chrome.

### Accessibility extras

- Landmark: `role="status"`, `aria-live="polite"`, `aria-atomic="true"`, `aria-label` as assembled above.
- File chrome wrapper: `aria-label="File"`.
- Current card: `data-scaffold-current` (scroll/test hook). Static segments: `data-scaffold-role="done" | "future" | "gap"`.
- CaptureSurface `#capture-surface` remains the only typing input.

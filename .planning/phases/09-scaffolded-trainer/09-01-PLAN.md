## Artifacts this phase produces

This plan owns:

- `sliceUnit(text: string, start: number, end: number): string` — `Array.from(text).slice(start, end).join('')` (D-19)
- `joinUnitSlices(text: string, units: readonly PlanUnit[]): string` — curriculum-order concat of `sliceUnit` results (SCAF-03 typedTarget)
- `coverFile(text: string, units: readonly PlanUnit[], unitIndex: number): ScaffoldSegment[]` — RESEARCH Pattern 2; sort a copy by `start`; classify role from index in the original `units` array vs `unitIndex`; fill `start > cursor` holes as `{ kind: 'gap'; start; end }`; trailing gap to code-point length
- `ScaffoldSegment` = `{ kind: 'gap'; start; end } | { kind: 'unit'; unit: PlanUnit; role: 'done' | 'current' | 'future' }`
- When `unitIndex >= units.length`, every unit role is `done` (post last-unit persist)
- `UnitSnapshot` = `{ events, charLog, markers }` matching the three live capture arrays
- `flattenSnapshots(snaps: readonly UnitSnapshot[]): Pick<Session, 'events' | 'charLog' | 'markers'>` — concat each array separately; remap `seq` on new objects (D-15)
- `assembleSessionFromLogs(exercise, logs, startedAt): Session` — same field order as `buildSession`; probes from `platform/isolation`; does not call `getEvents` / `getCharLog` / `getMarkers`

Do not create `src/scaffold/plan.ts`. Do not change Dexie. Do not change `buildSession`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User URL string → parseGithubRef | Untrusted host/path; must reject before any later fetch |
| CSP meta → browser network | connect-src is evaluated before CORS; listing origin must be explicit |
| GitHub path names → later UI | Names are untrusted text; this plan only stores strings on TreeNode |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-02 | Information disclosure | parseGithubRef / later client | high | mitigate | Allowlist github.com / www.github.com / nwo; never pass the raw user string to fetch (client concatenates api.github.com + encodeURIComponent parts) |
| T-07-03 | Tampering | foldTree paths | medium | mitigate | Treat path as data for node.name / node.path only; do not interpret as filesystem escapes; React text nodes in 07-03 |
| T-07-05 | Information disclosure | index.html CSP | high | mitigate | connect-src only 'self' and https://api.github.com; grep README + meta |
| T-07-04 | Information disclosure | errors.ts / future client | high | mitigate | No error class or type field for a personal access token; REPO-06 deferred |
| T-07-06 | Elevation of privilege | TreeNode.name | medium | mitigate | Strings only this plan; 07-03 renders as React text children |
| T-07-SC | Tampering | npm/pip/cargo installs | low | accept | This phase installs no packages (07-RESEARCH.md Package Legitimacy Audit is N/A) |

# Phase 7 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope of this phase's UI (per 07-CONTEXT.md D-01..D-16 + 07-RESEARCH.md):** a Trainer-only
> **Paste | GitHub** switch (one panel at a time); GitHub tab with URL field, explicit **Import**
> button, muted `owner/repo@default_branch` caption, hand-rolled nested `<ul>`/`<details>` tree,
> and one reserved status region. Browse-only: TS/JS clicks show a distinct “not yet” notice;
> non-TS/JS clicks show a blocked notice; neither calls `handleLoad` or fetches a blob. Out of
> scope: blob fetch, `sourceType: 'github'`, units/scaffold (Phases 8–9), branch picker, icons,
> tree libraries, fourth header item, remember-last-tab/URL.
>
> **This EXTENDS `01-UI-SPEC.md` through `06-UI-SPEC.md`.** All spacing / typography / color
> tokens below are inherited unchanged. **This phase introduces zero new color tokens and
> zero new type roles.** Reuse `src/index.css` (`.text-label`, `.text-muted`, `.control`,
> `.primary`, `--color-text`, `--color-text-muted`, `--color-destructive`, `--space-*`).

## Spacing Scale

Inherited unchanged from `01-UI-SPEC.md` (multiples of 4 only): `--space-xs` 4px, `--space-sm` 8px, `--space-md` 16px, `--space-lg` 24px, `--space-xl` 32px, `--space-2xl` 48px, `--space-3xl` 64px.

**Layout — page / header:** unchanged. Header stays three siblings (Trainer | History | Analytics). **No fourth “Repo” item** (CONTEXT carried-forward). `--column-max: 45rem` is not widened.

**Layout — corpus chrome (new this phase, D-01 / D-02):**

- Wrap today’s always-mounted `CorpusInput` plus the new GitHub panel in a **corpus shell** that is Trainer-only: `style={{ display: view === 'trainer' ? 'grid' : 'none' }}`. Never unmount. Never the `hidden` attribute (inline `display` would override it — Phase 4 D-08 lesson).
- Shell internal: `display: grid; gap: var(--space-md)`.
- History and Analytics no longer show paste, upload, the tab switch, the URL field, or the tree.

**Layout — Paste | GitHub switch (D-01 / D-03):**

- A `role="tablist"` `aria-label="Corpus source"` of two native `<button role="tab">` controls, `inline-flex`, `gap: var(--space-xs)` — same geometry as the header nav (`min-height: 44px`, `padding: var(--space-sm) var(--space-md)`).
- Tabs labeled **Paste** and **GitHub**. Paste is `aria-selected="true"` on first paint (D-03). Do not persist last tab.
- Selected tab treatment **matches header nav**, not accent: `[aria-selected="true"]` → `--color-surface` fill + weight 600 + `--color-text`. Unselected → transparent + weight 400 + `--color-text-muted`.
- Each panel is `role="tabpanel"` with `display: grid` when selected and `display: none` when not (D-04: switching is not a reset; paste text, language, GitHub field, and loaded tree stay mounted).
- The repo tree **never** shares space with the 8-row paste box.

**Layout — GitHub panel (`RepoBrowser`):**

Stacked grid, `gap: var(--space-md)`, matching `CorpusInput`:

1. **Form** — `display: grid; gap: var(--space-sm)`. Label (`class="text-label"`) → full-width text `<input class="control">` → primary **Import** button on its own row (same as “Load exercise”: wrapped in a single-child `<div>`, not stretched). Do not put URL + Import on one row.
2. **Caption** — one line, reserved `min-height: 1.4em; margin: 0`. Empty until a successful import. Muted. Does not live in the status region (07-RESEARCH.md Open Question 3).
3. **Tree** — nested `<ul>` disclosures inside a scroll container (see overflow exception). Absent until a successful import that returned at least one entry. Empty-repo / no-files success: omit the `<ul>`, keep the caption.
4. **Status region** — one `<p>` under the tree (or under the caption when there is no tree). Reserved `min-height: 48px` (`--space-2xl`) so two-sentence notices do not reflow the page (D-14, CorpusInput WR-05). `margin: 0`.

**Layout — tree rows:**

- Outer `<ul>`: `list-style: none; margin: 0; padding: 0; display: grid; gap: 0`.
- Nested `<ul>`: `list-style: none; margin: 0; padding-inline-start: var(--space-md)` (16px indent per level).
- Each directory is `<li><details [open]><summary>{name}</summary><ul>…</ul></details></li>`.
- Each file is `<li><button type="button">{name}</button></li>`.
- D-16: **only top-level** `<details>` receive the boolean `open` attribute (`open={depth === 0 ? true : undefined}`). Nested folders omit it. Never write `open={false}` / `open="false"`.

### Spacing exceptions

| Exception | Value | Rationale |
|-----------|-------|-----------|
| Tree file button / folder `<summary>` hit-target | `min-height: 32px` (`--space-xl`), `min-width: 0`, `padding: var(--space-xs) var(--space-sm)`, transparent background, no border, `border-radius: 4px`, `text-align: left`, `width: 100%` | Compact filesystem rows. Global `button` 44px floor would make a tall unreadable tree. 32px ≥ WCAG 2.5.8 24×24. Same exception class as `.save-failed-dismiss` / `.key-chip`. |
| Status region reserved height | `min-height: 48px` (`--space-2xl`) | Two-sentence notices (TS/JS not-yet, truncated) plus wrap at `--column-max`. 1.4em (CorpusInput) is too short here. |
| Caption reserved height | `min-height: 1.4em` | Same WR-05 pattern as CorpusInput file caption; one line. |
| Tree overflow | `max-height: 40vh; overflow: auto` on the tree wrapper | Matches `.preview`. A recursive listing must not push the trainer off-screen. Horizontal scroll only if a single unbreakable token still overflows after wrap. |
| Nested ul indent | `padding-inline-start: var(--space-md)` (16px) | Hierarchy without icons (D-13). |

No 44px exception for the tab buttons or Import — those stay on the global control floor.

## Typography

Inherited unchanged from `01-UI-SPEC.md` — reused, not redeclared. **Zero new sizes, zero new weights** (2-weight discipline 400/600 maintained):

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 15px | 400 | 1.5 |
| Label | 13px | 600 | 1.4 |
| Heading | 20px | 600 | 1.3 |
| Display | 28px | 600 | 1.2 |

- **Tab labels (`Paste`, `GitHub`):** Body 15px — selected weight 600 / `--color-text`, unselected weight 400 / `--color-text-muted` (same register as Trainer / History / Analytics nav).
- **URL field label:** Label role (13/600/1.4), `class="text-label"`.
- **URL field value / placeholder:** Body 15/400/1.5. Placeholder uses `--color-text-muted`.
- **Import button:** Body 15px, weight **600** (existing `.primary`).
- **Busy Import label (`Importing…`):** same as idle Import — do not shrink, do not italicize.
- **Caption `owner/repo@default_branch`:** Label role (13/600/1.4) + `text-muted` — same register as CorpusInput “Loaded from `{filename}`”.
- **Folder names and TS/JS file names:** Body 15/400/1.5, color `--color-text` (D-13).
- **Non-TS/JS file names:** Body 15/400/1.5, class `text-muted` (D-13).
- **Status — notices** (blocked, not-yet, truncated, empty-repo): Body 15/400/1.5, `text-muted`.
- **Status — errors** (invalid URL, 404, rate-limit, other HTTP, unreachable): Body 15/400/1.5, color `var(--color-destructive)`.
- **Long path / long file name:** wrap with `overflow-wrap: anywhere`. **No ellipsis, no truncation of the visible name** (REPO-02: every path GitHub returned stays readable). The tree wrapper scrolls vertically; wrapping is the long-text rule.

Display (28px) and Heading (20px) are **not** used inside the GitHub panel. The Trainer empty-state heading “No exercise loaded” is unchanged from Phase 1.

No italic. No letter-spacing adjustments.

| — accent text-on | `--color-accent-text-on` | Label on the Import primary fill |

**Accent reserved for (explicit, exhaustive — Phase 7 additions in bold):**

1. Primary buttons (“Load exercise”, “Restart exercise”, **“Import”**) — solid accent fill.
2. The focus ring on every interactive element (now also **Paste/GitHub tabs, URL field, Import, folder `<summary>`, tree file buttons**) — 2px accent outline, `outline-offset: 2px`. Never removed.
3. The capture `<textarea>` border while focused — unchanged.
4. The custom trainer caret — unchanged.

Accent is **never** used for: the selected Paste/GitHub tab (surface + weight, like header nav), folder/file names, status notices, truncated callouts, or decorative tree chrome.

**Semantic split in the status region:**

- Errors (`role="alert"`) → `--color-destructive`.
- Notices (`role="status"`) → `--color-text-muted`.
- Do not paint TS/JS rows accent to imply they are “ready.” They use `--color-text` only. No selection highlight (D-07).

## Copywriting Contract

Copy lives as a `COPY` const in `src/ui/RepoBrowser.tsx`, verbatim from this table. Do not paraphrase in implementation. Voice: plain, second person, no exclamation points. Never blames the user. Every error names the fix. **No “Phase 8”, no parser/WASM/tree-sitter jargon** (D-06).

| Element | Copy |
|---------|------|
| Primary CTA | **Import** |
| Empty state heading | none in the GitHub panel — no extra `<h2>`. Trainer “No exercise loaded” is unchanged from `01-UI-SPEC.md`. |
| Empty state body (never imported) | none — the labeled URL field + Import **is** the empty GitHub panel. Do not invent a “paste a URL to get started” paragraph under the form. |
| Empty repo / no files (successful import, 409 or `tree: []`) | This repository has no files on the default branch. |
| Error state (generic — do not use) | never “Failed to fetch.” Never a stack trace. Never a toast. |
| Destructive confirmation | **not applicable** — Phase 7 has no destructive action. |

**Supporting copy (locked this phase):**

| Element | Copy |
|---------|------|
| Tab — paste | Paste |
| Tab — github | GitHub |
| URL field label | GitHub URL or owner/repo |
| URL field placeholder | owner/repo or https://github.com/owner/repo |
| Import — idle | Import |
| Import — busy | Importing… |
| Caption (after success) | `{owner}/{repo}@{defaultBranch}` — e.g. `facebook/react@main`. No “Loaded from” prefix. Interpolate the API `default_branch` string verbatim. |
| Invalid URL (gist, GitLab, raw, other host, missing owner/repo, whitespace-only) | Paste a GitHub URL or owner/repo. |
| 404 / private (GitHub 404s both — one string) | No public GitHub repository matches that URL. |
| Rate limit — reset time known | GitHub rate-limited this browser. Try again after {time}. |
| Rate limit — reset time unknown | GitHub rate-limited this browser. Try again in a few minutes. |
| Other HTTP (403 that is not remaining=0, 5xx, unnamed status) | GitHub refused this request. Try again later. |
| Unreachable (TypeError / CSP / COEP / network) | Couldn't reach GitHub. Check the connection and try again. |
| Truncated tree (`truncated: true`, still render entries) | GitHub returned a partial file list (repository too large). Showing what arrived. |
| Blocked file (not `.ts` / `.tsx` / `.js` / `.jsx`, including `.mjs` `.cjs` `.mts` `.cts`, README, submodules) | This file can't be split yet. No exercise loaded. |
| TS/JS not-yet (`.ts` `.tsx` `.js` `.jsx`, including `.d.ts`) | TypeScript/JavaScript files open as scaffolded exercises in the next step. Browsing only for now. |

**Rate-limit `{time}` format:** `new Date(resetEpochS * 1000).toLocaleTimeString(undefined, { hour: 'numeric', minute: '2-digit' })` — local wall clock, no seconds, no date, no timezone abbreviation. Example: `4:37 PM`.

**Not introduced (explicit, to prevent scope creep):**

- No “Open as exercise”, no “Select file”, no dismiss control on the status region (D-08).
- No “Phase 8” / “coming soon” / “parser” / “WASM” in any string (D-06).
- Do not reuse the blocked sentence for TS/JS clicks (that would imply TypeScript cannot be split).
- Do not change CorpusInput `COPY` (`Load exercise`, upload errors, “Loaded from `{filename}`”).
- Do not change Trainer empty-state “No exercise loaded” / “Paste code or text below…” — GitHub import does not load an exercise this phase, so that copy must not claim it does.

## Interaction Contract

### Tabs and persistence (D-01..D-04)

- Paste is the default tab on every full page load. Do not read or write last-tab in `localStorage`.
- Switching Paste ↔ GitHub does **not** clear paste text, paste language, GitHub URL value, caption, tree, or status.
- Loading a paste/upload exercise does **not** discard the GitHub tree.
- Corpus shell `display: none` on History and Analytics; returning to Trainer restores the last selected corpus tab **within the session** (in-memory only).
- `RepoBrowser` does **not** take `onLoad` this phase and must not call `handleLoad`.

### Import (D-09..D-11)

- Fetch runs only on **Import** click or **Enter** in the URL field (`<form onSubmit>` → `preventDefault` → `onImport`). **No fetch-on-paste, no fetch-on-change, no debounce fetch.**
- URL field is `type="text"` (not `type="url"` — `owner/repo` must be valid), `spellCheck={false}`, `autocomplete="off"`, `class="control"`, `width: 100%`. Visible label via `htmlFor` — placeholder is not the label.
- `aria-invalid="true"` on the URL field only while the status region shows the invalid-URL string. Clear `aria-invalid` on the next Import start.
- Import button: `type="submit"`, `class="primary"`, `disabled={busy}`. Label swaps to **Importing…** while in flight. URL field stays enabled so the user can edit.
- No programmatic focus move on success or error.

**Last-wins second Import (discretion locked):**

1. Every Import increments a monotonic token (CorpusInput analogue). Only the current token may write tree, caption, status, or busy.
2. On Import **start:** set busy; **clear the status region immediately** (blocked, not-yet, truncated, empty, and errors all go). Previous tree and caption stay until a new **success** lands — no empty flash.
3. On **success:** replace tree and caption with the new repo. Status empty, unless `truncated: true` (then truncated notice) or the listing has zero files (then empty-repo notice, no `<ul>`).
4. On **error** (invalid URL, 404, rate-limit, other HTTP, unreachable): do **not** replace tree or caption (a previous successful import stays browseable). Write the error into the status region.
5. Empty-repo (HTTP 409) and `tree: []` are **successes**: replace any previous tree with the empty listing (no `<ul>`), set caption, status = empty-repo copy.

### Tree (D-05..D-08, D-12..D-16)

- Hand-rolled nested `<ul>` + `<details>` / `<summary>`. No `role="tree"` (MDN: `<details>` implicit role is `group`; no role permitted). Native Space/Enter on `<summary>` toggles.
- Folders: click toggles expand/collapse only. **Folders never write the status region** and never show blocked/not-yet copy.
- Files are `<button type="button">`. Accessible name = the file’s basename (React text child `{node.name}`). Path names are React text nodes / `textContent` only — **no `innerHTML`, no `dangerouslySetInnerHTML`, no markdown** (PITFALLS XSS).
- Loadable extensions are exactly `.ts` `.tsx` `.js` `.jsx` (case-insensitive). `.d.ts` is loadable (suffix `.ts`). `.mjs` `.cjs` `.mts` `.cts` take the blocked path. Extension test is **not** `extToLang`.
- TS/JS click: write the not-yet string into the status region with `role="status"`. **No blob fetch. No `handleLoad`. No selection / `aria-current` / highlight** (D-07). Same file or another file **replaces** the message. No dismiss button (D-08).
- Non-TS/JS file click (including `type: commit` submodules): write the blocked string into the status region with `role="status"`. No exercise loads.
- A file click **replaces** a truncated notice if one was showing (one region — D-14). Truncated reappears only on the next successful truncated import.
- First successful import: top-level folders open, nested collapsed (D-16). A later Import of another repo resets expand state to that rule. Tab-away and tab-back do **not** reset expand state (hide-not-unmount).

### Status region (D-14)

One reserved `<p>` under the tree. Role tracks the branch, matching CorpusInput WR-05:

| Kind | `role` | Color |
|------|--------|-------|
| invalid URL, 404, rate-limit, other HTTP, unreachable | `alert` | `--color-destructive` |
| blocked, TS/JS not-yet, truncated, empty-repo / no files | `status` | `--color-text-muted` |
| idle / cleared | `status` | n/a (empty text, height still reserved) |

When the region is empty, keep `role="status"` and `min-height: 48px` so the slot does not collapse.

### Keyboard

- Tab order inside GitHub panel: Paste tab → GitHub tab → URL field → Import → (if tree) folder summaries and file buttons in DOM / visual order, depth-first.
- Enter in the URL field submits Import.
- Folder `<summary>`: native Enter/Space toggle.
- File buttons: Enter/Space fires the same click handler as pointer (notice only).
- No mouse-only tree affordance.

### Motion

- No new animation this phase. Existing `button` border/outline transition (≤ 150ms, `prefers-reduced-motion: no-preference`) applies to Import and tabs. Tree expand/collapse is native `<details>` — do not add height transitions.
- Busy state is the **Importing…** label + disabled button. No spinner library.

### Accessibility extras

- Tablist: `aria-controls` on each tab pointing at the matching `tabpanel` `id` (`corpus-panel-paste`, `corpus-panel-github`). Active tab `aria-selected="true"`; inactive `aria-selected="false"`.
- Tree wrapper: `aria-label="Repository files"`.
- Import busy: `aria-busy="true"` on the form while in flight; `false` otherwise.

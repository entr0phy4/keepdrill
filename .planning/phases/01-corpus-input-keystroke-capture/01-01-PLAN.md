<objective>
Stand up the keebdrill walking skeleton: a Vite 8 + React 19 + TypeScript SPA
that loads pasted text through a pure normalizer into an in-memory `Exercise`,
renders it as an inert preview, focuses a native `<textarea>` capture surface, and
appends every `keydown` / `keyup` to an append-only high-resolution
`KeystrokeEvent[]` — served cross-origin-isolated with `crossOriginIsolated`
verified and the achieved timer resolution recorded on the `Session`.

Purpose: this is the Phase-1 tracer. It proves the whole input -> normalize ->
capture -> cross-origin-isolated pipe on the architecture every later phase
inherits, and it establishes the pure-core / platform-coupled-seam / hot-path
patterns Phases 2-3 copy. An architectural dead-end here costs one commit instead
of ten.

Output: the project scaffold, the `src/{ingestion,capture,platform,ui}` module
tree with a thin but production-quality end-to-end path, a passing 18-case
normalizer golden suite, a happy-dom capture proof, and `SKELETON.md`.
</objective>

## Phase Goal (MVP user story)

**As a** developer using keebdrill, **I want to** load real code or text as a
typing-ready exercise and have every keystroke captured at high resolution into a
complete append-only log, **so that** the speed, accuracy and slowest-key numbers
in later phases are computed from a trustworthy source of truth.

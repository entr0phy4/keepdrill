# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope of this phase's UI (per 01-CONTEXT.md §specifics + orchestrator scope note):** a corpus paste box, a file-upload control, a "Load exercise" action, an exercise preview, an always-focused capture `<textarea>` (a plain focused input — *not* a styled trainer), a static "US ANSI layout only" notice banner, and a "timing may be degraded" warning banner shown when `crossOriginIsolated !== true`. The trainer view (caret, per-character coloring, whitespace glyphs, results panel) is **Phase 2 / Phase 3** and is explicitly out of scope here.
>
> **This is the greenfield token foundation.** No design system existed before this file. The tokens below are the seed that Phases 2-3 extend — kept intentionally small and defensible.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (hand-rolled CSS custom properties) |
| Preset | not applicable |
| Component library | none — native HTML elements (`<textarea>`, `<input type="file">`, `<button>`) styled directly |
| Icon library | none (Phase 1 has no icons; if introduced later, inline self-hosted SVG only — COEP `require-corp` forbids third-party asset hosts) |
| Font | System monospace stack (self-hosted-free, zero network): `ui-monospace, "SF Mono", "JetBrains Mono", "Cascadia Code", Menlo, Consolas, "Liberation Mono", monospace` |

**Rationale for `Tool: none`:** shadcn was considered and declined for Phase 1. The user-facing surface is five primitive controls; the security domain (01-RESEARCH.md §Security Domain) mandates zero third-party runtime scripts and self-hosted assets under COEP `require-corp`; and the project runs autonomously with no interactive design channel. Revisit shadcn at Phase 2 if the trainer needs real composite components. All tokens are exposed as CSS custom properties on `:root` (and `:root` under `@media (prefers-color-scheme: dark)`) so a later adoption can map onto them.

**Product identity:** keyboard-centric developer tool — monospace-forward, terminal-adjacent, calm. All UI text is monospace (not just code), which is the aesthetic signal. Works in light and dark; theme follows `prefers-color-scheme` with no manual toggle in Phase 1.

## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| `--space-xs` | 4px | Icon-less inline gaps, tight label-to-control spacing |
| `--space-sm` | 8px | Compact stack spacing, gap between banner icon-slot and text |
| `--space-md` | 16px | Default gap between form controls, control inner padding (x) |
| `--space-lg` | 24px | Page gutter, gap between major regions (input group ↔ preview ↔ capture) |
| `--space-xl` | 32px | Top/bottom page padding on desktop, gap above the first region |
| `--space-2xl` | 48px | Reserved — not used in Phase 1 layout |
| `--space-3xl` | 64px | Reserved — not used in Phase 1 layout |

**Exceptions:** none. Interactive controls (button, file-picker label, textareas) have a **minimum hit target of 44px height** — this is a sizing floor, not a spacing token, and is achieved via padding + line-height, never via an off-scale margin.

**Layout:** single centered column, `max-width: 45rem` (720px). Column padding: `--space-lg` (24px) on viewports < 640px, `--space-xl` (32px) top/bottom above that. Banners render full-column-width, stacked, directly above the input group (both may show at once).

## Typography

All roles use the monospace stack. Two weights only: 400 (regular), 600 (semibold).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 15px | 400 | 1.5 |
| Label | 13px | 600 | 1.4 |
| Heading | 20px | 600 | 1.3 |
| Display | 28px | 600 | 1.2 |

- **Body (15px/400/1.5):** paste box text, exercise preview text, capture `<textarea>` text, banner body copy, helper/meta text (e.g. the timer-resolution readout — same size, muted color).
- **Label (13px/600/1.4):** form field labels ("Paste code or text", "Upload a file"), banner lead-in word ("Notice", "Heads up"), selected-filename caption.
- **Heading (20px/600/1.3):** region headings if used ("Exercise", "Type here").
- **Display (28px/600/1.2):** the app title ("keebdrill") in the page header — one instance.

No italic. No letter-spacing adjustments. Tabular figures are inherent to monospace.

## Color

Theme follows `prefers-color-scheme`. Every value below is a CSS custom property with a light default and a dark override. Contrast: all text/background pairs meet WCAG AA (≥ 4.5:1 for body, ≥ 3:1 for large text and UI borders).

|------|-------|-------|
| Dominant (60%) | `#FAFAF9` | Page background |
| Secondary (30%) | `#EFEEEC` | Card / input / preview / banner surfaces |
| — border | `#D6D5D1` | Control borders, region dividers, neutral banner left-border |
| — text primary | `#1C1C1A` | Body and headings |
| — text muted | `#5C5C57` | Helper text, timer readout, placeholder |
| Accent (10%) | `#1A7F37` | See reserved list below |

| Warning text | `#7A5C00` | "Timing may be degraded" banner text + left-border |

### Dark

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0D1117` | Page background |
| Secondary (30%) | `#161B22` | Card / input / preview / banner surfaces |
| — border | `#30363D` | Control borders, region dividers, neutral banner left-border |
| — text primary | `#E6EDF3` | Body and headings |
| — text muted | `#8B949E` | Helper text, timer readout, placeholder |
| Accent (10%) | `#3FB950` | See reserved list below |
| — accent text-on | `#0D1117` | Text/label on accent fill |

| Warning surface | `#272115` | "Timing may be degraded" banner background |
| Warning text | `#D29922` | "Timing may be degraded" banner text + left-border |

**Accent reserved for (explicit, exhaustive):**
1. The primary button ("Load exercise") — solid accent fill.
2. The focus ring on every interactive element (paste box, file-picker label, Load button, capture `<textarea>`) — 2px accent outline, `outline-offset: 2px`.
3. The capture `<textarea>` border while it holds focus (the "you are being recorded / type here" signal).

Accent is **never** used for body text, headings, links, the US-ANSI notice banner, borders at rest, or decorative fills.

**Semantic colors:** `Warning` is the only added semantic beyond `Destructive`, and it exists solely for the degraded-timing banner (a genuine, spec-required state from D-16). The US-ANSI notice banner is **neutral** — secondary surface + muted text + neutral left-border — so accent stays scarce.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | **Load exercise** |
| Empty state heading | **No exercise loaded** |
| Empty state body | Paste code or text below, or upload a file, then choose **Load exercise** to begin. |
| Error state — not UTF-8 | This file isn't UTF-8 text. Save it as UTF-8, or paste the contents instead. |
| Error state — too large | This file is over 100 KB. Paste a smaller section, or trim the file first. |
| Error state — nothing to load | Nothing to load yet. Paste text or choose a file first. |
| Destructive confirmation | none — Phase 1 has no destructive actions |

**Supporting copy (non-CTA):**

| Element | Copy |
|---------|------|
| Paste field label | Paste code or text |
| Paste field placeholder | Paste a snippet, a file's contents, anything you want to drill… |
| File field label | Or upload a file |
| File picker button | Choose file |
| Selected-file caption | Loaded from `{filename}` |
| Capture surface label | Type here |
| Capture surface placeholder | (empty — no placeholder; a blinking caret is the only affordance) |
| Timer-resolution readout | Timer resolution: `{n}` µs |
| US-ANSI notice banner (lead-in + body) | **Notice** — Built and tested for the US ANSI keyboard layout. Other layouts may mismatch on symbol keys. |
| Degraded-timing warning banner (lead-in + body) | **Heads up** — High-resolution timing isn't available here, so keystroke measurements may be less precise. Open the deployed site over a cross-origin-isolated connection for best results. |
| Paste-into-capture blocked (inline flag) | Pasting into the typing area is disabled — type the exercise to record real keystrokes. |

Voice: plain, second person, no exclamation points except none. Never blames the user. Every error names the fix.

Applicable state considerations resolved: **6 covered, 2 backstop, 0 unresolved**

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | exercise preview / capture surface | ✅ covered | Before load, the preview region shows the `## Copywriting Contract` "No exercise loaded" heading + body; the capture `<textarea>` is not rendered (or rendered disabled) until an `Exercise` exists. |
| error | file upload (`upload.ts`) | ✅ covered | Non-UTF-8, over-100 KB, and empty-input errors render the three documented error strings inline beneath the file control, in `text primary` on `Warning surface`, dismissed on next successful action. No stack traces, no toast. |

| loading | file read + `normalize()` | 🧪 backstop | For < 100 KB inputs the operation is effectively synchronous; the Load button enters a disabled "Loading…" state only if the transform exceeds one frame (large paste path, per 01-RESEARCH Pitfall 6). ## Interaction Contract

- **Theme:** respects `prefers-color-scheme`; no in-app toggle. All color tokens flip via a single `@media` block.
- **Focus:** visible 2px accent outline on every interactive element, `outline-offset: 2px`, never removed. Tab order: page title → paste box → Choose file → Load exercise → (post-load) capture surface.
- **Capture surface focus:** on successful load, focus moves programmatically to the capture `<textarea>` *after* the capture listeners are attached (01-RESEARCH Pitfall 2). It reclaims focus on click anywhere in the preview/capture region.
- **Paste policy:** paste is **allowed** in the corpus paste box (INPUT-01). Paste is **blocked and flagged** in the capture `<textarea>` via selective `preventDefault` on `beforeinput` `insertFromPaste` (CAPT-04); the inline flag copy appears for ~4s then fades.
- **Keyboard:** Load exercise fires on Enter/Space when focused. No mouse-only affordances.
- **Motion:** the only transitions are focus-ring and banner-appearance fades, ≤ 150ms, all wrapped in `@media (prefers-reduced-motion: no-preference)`. Nothing animates on keystroke (would jitter timing — 01-RESEARCH Anti-Patterns).
- **No layout shift:** banners occupy their space from first paint (they are known at startup); loading an exercise expands the preview region downward only, never reflows controls above it.

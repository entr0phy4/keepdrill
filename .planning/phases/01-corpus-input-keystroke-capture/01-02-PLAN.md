  <behavior>
    fromFile(file, tabWidth = 4): Promise<Exercise>
    - file.size > 100_000 -> rejects with CorpusTooLargeError (sizeBytes = file.size); File.text() is never called
    - decoded text includes U+FFFD, OR raw bytes start with 0xFF 0xFE / 0xFE 0xFF -> rejects with NonUtf8Error (fileName = file.name)
    - clean UTF-8 file -> resolves { text: normalize(raw, {tabWidth}), language: extToLang(file.name), sourceType: 'upload', sourceRef: file.name }
    - a file with CRLF line endings and tabs -> text is normalized identically to fromPaste of the same string
    - empty (0-byte) file -> resolves an Exercise whose text is "" (normalize of "" stays "")

    extToLang(fileName): string
    - '.ts'/'.tsx' -> 'typescript'; '.js'/'.jsx' -> 'javascript'; '.py' -> 'python';
      '.rs' -> 'rust'; '.go' -> 'go'; '.sh'/'.bash' -> 'bash'; '.sql' -> 'sql';
      '.json' -> 'json'; '.yaml'/'.yml' -> 'yaml'; '.md'/'.markdown' -> 'markdown';
      '.html' -> 'html'; '.css' -> 'css'; '.toml' -> 'toml'
    - no extension, unknown extension, or a dotfile with no suffix -> 'plaintext'
    - case-insensitive on the extension
  </behavior>
  <action>
    `src/ingestion/errors.ts`: two `Error` subclasses. `CorpusTooLargeError` carries
    a readonly `sizeBytes: number`; `NonUtf8Error` carries a readonly `fileName: string`.
    Set `this.name` on each. No other logic.

    `src/ingestion/language-map.ts`: `extToLang(fileName: string): string` — a plain
    `Record<string, string>` keyed by lower-cased extension (with leading dot),
    `'plaintext'` fallback (D-11 says paste is `'plaintext'`; unknown uploads match).
    Extension map contents are Claude's discretion (CONTEXT.md) — use the
    `<behavior>` list.

    `src/ingestion/upload.ts`: lift 01-RESEARCH.md "File upload -> Exercise" verbatim
    and harden the encoding check. Order:
    1. `if (file.size > 100_000) throw new CorpusTooLargeError(file.size)` — BEFORE
       reading (PITFALLS #6 / A5).
    2. Read the first 2 bytes via `file.slice(0, 2).arrayBuffer()`; if they are
       `0xFF 0xFE` or `0xFE 0xFF`, `throw new NonUtf8Error(file.name)` (UTF-16 BOM —
       PITFALLS #7).
    3. `const raw = await file.text()` — the modern promise-based UTF-8 read; do
       not hand-roll charset sniffing (RESEARCH Don't Hand-Roll).
    4. `if (raw.includes('�')) throw new NonUtf8Error(file.name)`.
    5. `return { text: normalize(raw, { tabWidth }), language: extToLang(file.name),
       sourceType: 'upload', sourceRef: file.name }` — `sourceType` / `Exercise`
       field names verbatim from D-11.
    Do NOT parse, strip, or transform the content beyond `normalize()` (D-08). Do
    NOT use `file.name` for anything but `sourceRef` (T-01-06).

    `src/ingestion/upload.test.ts` (Vitest, `environment: 'node'`): construct `File`

| file metadata -> UI / Exercise | `file.name` is attacker-influenced text shown in the caption and stored on `Exercise.sourceRef` |
| in-memory corpus -> DOM | Uploaded text is rendered into the preview (`<pre>`) and must stay inert |

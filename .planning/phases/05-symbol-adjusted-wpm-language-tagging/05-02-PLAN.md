<objective>
Give the paste path a manual language `<select>` (D-11) so a pasted exercise can carry a real
language tag instead of always defaulting to `'plaintext'` — a closed, code-defined enum
control, never a free-text field, never blocking "Load exercise" (D-14).

**Assumption-delta decision (recorded per orchestrator instruction): add-alongside, not
promote.** This plan introduces no new identity/platform/tenant/source-of-truth concept — it
adds one explicit `language` parameter to an existing pure function (`fromPaste`) and one form
control to an existing component (`CorpusInput`). The upload path's existing `extToLang`
auto-tagging is completely untouched (D-11's explicit scope: "paste path only").

Purpose: satisfies ANLY-02 (paste-only language picker/confirm). Establishes one canonical
language vocabulary (`PASTE_LANGUAGE_OPTIONS`, derived from `language-map.ts`'s existing
`EXT_TO_LANG` map) that both paste and upload draw from, which Phase 6's per-language profile
will depend on.

Output: `PASTE_LANGUAGE_OPTIONS` export (`src/ingestion/language-map.ts`), `fromPaste`'s new
required-parameter signature (`src/ingestion/paste.ts`), the fixed `upload.test.ts:71` call
site, the new `<select>` + wiring in `src/ui/CorpusInput.tsx`, and a new
`src/ui/CorpusInput.test.tsx`.
</objective>

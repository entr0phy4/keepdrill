| public wasm → Parser.init | locateFile must stay same-origin so COEP require-corp holds |

| T-08-04 | Elevation of privilege | index.html CSP | high | mitigate | script-src 'self' plus wasm-compile token only; do not add the general eval keyword; connect-src unchanged |
| T-08-05 | Tampering | public/*.wasm / vite.config.ts | high | mitigate | Copy wasm from the verified packages into public/; never CDN; do not edit COEP require-corp |
| T-08-09 | Tampering | Parser.init locateFile | high | mitigate | Serve runtime wasm from public/ under the basename locateFile receives; 08-04 will set locateFile to /${scriptName} |
| T-08-SC | Tampering | pnpm add web-tree-sitter / tree-sitter-typescript | high | mitigate | blocking-human verify on npmjs.com before install; --ignore-scripts on the grammar; no CLI unless both pins fail (then stop) |

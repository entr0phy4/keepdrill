# Phase 6 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope of this phase's UI (per 06-CONTEXT.md + 06-RESEARCH.md):** one new **Analytics** sibling
> view (D-01) — a stacked, read-only dashboard of three sections in this order: **slowest-digraph
> table → US-ANSI keyboard heatmap → per-language profile table** (D-02). Reached from a third
> header item. History stays its own list. Trainer hide-not-unmount (Phase 4 D-08) extends to this
> flip. Out of scope: trigraphs (ANLY-06), per-session drill-down (ANLY-07), language filters
> (ANLY-08), trend charts, live heatmap, jump-nav / TOC (D-03).
>
> **This EXTENDS `01-UI-SPEC.md` through `05-UI-SPEC.md`.** All spacing / typography / color tokens
> below are inherited unchanged unless explicitly introduced as new. Do not re-derive the token
> foundation. **This phase introduces exactly three new color tokens** (`--heatmap-lo`,
> `--heatmap-hi`, `--heatmap-key-fg`) plus keyboard-grid layout rules. No other new tokens.

## Spacing Scale

Inherited unchanged from `01-UI-SPEC.md` (multiples of 4 only): `--space-xs` 4px, `--space-sm` 8px, `--space-md` 16px, `--space-lg` 24px, `--space-xl` 32px, `--space-2xl` 48px, `--space-3xl` 64px.

### Layout — header (extends Phase 4)

- The existing header flex row is unchanged (`align-items: baseline; justify-content: space-between; gap: var(--space-md); flex-wrap: wrap`).
- The `<nav>` stays `inline-flex` with `gap: var(--space-xs)`.
- **Add a third native `<button>`** labeled `Analytics` after `History` (D-01). Same global `button` sizing (`min-height: 44px`, `padding: var(--space-sm) var(--space-md)`). All three buttons render from first paint — no layout shift when the active view changes.
- Active treatment is unchanged: `[aria-current="page"]` gets `--color-surface` fill + weight 600 + `--color-text`. Inactive stays transparent + weight 400 + `--color-text-muted`. **Do not use `--color-accent` for the active Analytics button** (04-UI-SPEC "Why the active view toggle is NOT accent-colored").

### Layout — Analytics page

- Renders in the **same main-grid slot** History uses. When `view === 'analytics'`, the trainer wrapper is `display: none` (never unmounted, D-08) and `<AnalyticsDashboard>` mounts. `{view === 'history' && <HistoryView />}` stays as-is.
- **`CorpusInput` stays visible** on Analytics (match History; 06-RESEARCH.md Discretion). Loading an exercise from Analytics does not auto-flip back to Trainer.
- `<AnalyticsDashboard>` internal: `<h2>Analytics</h2>` → `var(--space-lg)` (24px) gap → loading / page-empty / three sections. Reuse History's `role="status"` + `display: grid; gap: var(--space-lg)` wrapper.
- **Page empty / loading:** a single muted `<p>` (`margin: 0; padding-block: var(--space-md)`), same class treatment as `.history-empty` / `.history-loading`. **Do not mount the three sections** when `sessions === undefined` or `sessions.length === 0` (D-04).
- **Populated:** three stacked `<section>`s in this **fixed** order (D-02), **scroll only — no jump links, no TOC, no in-page index** (D-03):
  1. Slowest digraphs — **primary visual anchor** of the page (checker FLAG: heatmap color/size must not read as the hero; Display 28px is unused)
  2. Keyboard heatmap — diagnostic, secondary
  3. Language profile
- Gap between sections: `var(--space-xl)` (32px). Each section is `display: grid; gap: var(--space-md)` — heading → body.
- No independent page-level scroll container. The dashboard grows the page downward with normal document flow (same as History). `--column-max: 45rem` is **not** widened.

### Layout — digraph table + language table

- Semantic `<table class="analytics-table">` — not a card-grid, not a chart (D-05, D-16).
- `width: 100%; border-collapse: collapse;`
- Cell padding: `var(--space-sm)` (8px) block / `var(--space-md)` (16px) inline.
- Header row: bottom border `1px solid var(--color-border)`.
- Body rows: no card chrome, no hover elevation, no zebra that implies interactivity. Optional 1px `--color-border` hairline between rows.
- Numeric columns (`Median`, `Samples`, `WPM`, `Adj. WPM`, `Accuracy`, `Sessions`) are `text-align: right`.
- Digraph glyph and language tag reuse `.key-chip` (Phase 3/4 padding: `--space-xs` / `--space-sm`, 4px radius, 1px `--color-border`). Chip background inside a table sitting on `--color-bg` is `--color-surface` (inverse of History-row chips, which sit on surface and use `--color-bg`).
- Digraph table is **at most 10 data rows** (D-05). Language table is **one row per distinct `exercise.language`** (D-19) — grows with the page, no inner scroll, no virtualization.

### Layout — keyboard heatmap (new)

- A **static US-ANSI QWERTY diagram** (`div` CSS grid), never a list, never an `<ol>` of keys (D-10).
- Wrapper `.keyboard-heatmap`: `overflow-x: auto` as the **last-resort** overflow (Pitfall 10). Page-level jump nav remains forbidden (D-03). Do not change `--column-max`.
- Grid: 5 rows × 15 columns. `grid-template-columns: repeat(15, minmax(32px, 1fr)); gap: var(--space-xs)` (4px). Row stagger via `grid-column` spans/offsets — not absolute positioning, not `getBoundingClientRect`.
- Keys drawn (W3C `KeyboardEvent.code`, US 101 alphanumeric block only — 06-RESEARCH.md Discretion): `Backquote`, `Digit0`–`Digit9`, `Minus`, `Equal`, `Backspace`, `Tab`, `KeyQ`–`KeyP`, `BracketLeft`, `BracketRight`, `Backslash`, `CapsLock`, `KeyA`–`KeyL`, `Semicolon`, `Quote`, `Enter`, `ShiftLeft`, `KeyZ`–`KeyM`, `Comma`, `Period`, `Slash`, `ShiftRight`, `ControlLeft`, `MetaLeft`, `AltLeft`, `Space`, `AltRight`, `MetaRight`, `ControlRight`. **Omitted entirely:** F-row, arrows, nav cluster, numpad, `Intl*`.
- Each key `.kb-key`: `min-width: 32px; min-height: 48px; padding: var(--space-xs); border: 1px solid var(--color-border); border-radius: 4px; display: grid; align-content: center; justify-items: center; gap: 0`. Label stacked above the ms number.
- Spans (column units): `Backspace` 2, `Tab` 1.5 → implement as `span: 2`, `CapsLock` 2, `Enter` 2, `ShiftLeft` / `ShiftRight` 3, `Space` 7, remaining writing-system keys 1. Exact integer spans must keep the 15-column silhouette recognizable; do not hide unused keys to "make it fit" (D-13).
- Always mount the diagram when sessions exist (D-13). If zero keys clear the 5-sample gate, every key stays on the diagram with **neutral fill and no number**, plus the muted caption under the figure.

### Spacing exceptions

| Exception | Value | Rationale |
|-----------|-------|-----------|
| Heatmap key hit-target | `min-height: 48px`, `min-width: 32px` — **not** the 44px control floor | Keys are inert diagnostic cells, not buttons (D-15 / D-10). 48px is a declared scale multiple (`--space-2xl`) so label + ms can stack. |
| Heatmap key padding / radius | `--space-xs` / 4px | Same compact `<kbd>` class as `.key-chip`. |
| Heatmap key gap | `--space-xs` (4px) | Tight enough for a 15-column row inside `--column-max`. |
| Heatmap horizontal overflow | `overflow-x: auto` on `.keyboard-heatmap` only | Last resort at viewports ≲ 360px. The page itself does not grow a horizontal scrollbar. |

## Typography

Inherited unchanged from `01-UI-SPEC.md` — reused, not redeclared. **Zero new sizes, zero new weights** (2-weight discipline 400/600 maintained):

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 15px | 400 | 1.5 |
| Label | 13px | 600 | 1.4 |
| Heading | 20px | 600 | 1.3 |
| Display | 28px | 600 | 1.2 |

- **"Analytics" page heading and the third nav label:** Heading role (20/600/1.3) for `<h2>Analytics</h2>`; nav button `Analytics` is Body 15px — **active** weight 600 / `--color-text`, **inactive** weight 400 / `--color-text-muted` (same as Trainer / History).
- **Section titles** (`Slowest digraphs`, `Keyboard heatmap`, `Language profile`): Label role (13/600/1.4), muted — same register as ResultsView's "Slowest keys". These are `<h3 class="text-label text-muted">`.
- **Table header cells:** Label role (13/600/1.4), muted.
- **Table body — glyphs / language chip text:** Body 15/400/1.5 (chip glyph primary, matching History language chips).
- **Table body — numeric values** (ms, n, WPM, adj. WPM, accuracy %): Body 15px, weight **600**, `--color-text`. Deliberately *not* Display — this is a diagnostic list, not a single-session results panel.
- **Heatmap key legend label** (unshifted glyph, e.g. `A`, `1`, `;`): Label role (13/600/1.4), color `--heatmap-key-fg` on sampled keys, `--color-text` on unused/non-sampleable keys.
- **Heatmap on-key ms number:** Label role (13/600/1.4), color `--heatmap-key-fg`. Render `{Math.round(medianMs)}` with **no `ms` unit on the key** (the figure caption carries the unit). Unused / below-gate / non-sampleable keys render **no number** (D-13).
- **Empty / loading / heatmap-ungated caption:** Body 15/400/1.5, muted.
- **Whitespace digraph glyphs:** `glyphFor` — space → `·` (U+00B7), newline → `↵` (U+21B5). Other codepoints render as themselves. Join the two mapped codepoints with no separator.

No italic, no letter-spacing adjustment, no count-up / tabular animation. Display role (28px) is **not** used on this page.

## Color

Theme continues to follow `prefers-color-scheme`, no manual toggle. Existing tokens are unchanged. **This phase adds three heatmap tokens only.** They are diagnostic intensity, **not** a score and **not** accent/destructive.

| Role | Token | Usage in this phase |
|------|-------|---------------------|
| Dominant (60%) | `--color-bg` | Page background; Analytics table sits on it |
| Secondary (30%) | `--color-surface` | Active nav fill; `.key-chip` fill on this page; **unused and non-sampleable heatmap keys** (D-13) |
| — border | `--color-border` | Table hairlines; heatmap key borders; chips |
| — text primary | `--color-text` | Table numbers, chip glyphs, active nav, unused-key labels |
| — text muted | `--color-text-muted` | Section titles, table headers, empty/loading/ungated copy, inactive nav |
| Heatmap low (fastest gated) | `--heatmap-lo` | Sequential scale start — keys with the **lowest** gated median |
| Heatmap high (slowest gated) | `--heatmap-hi` | Sequential scale end — keys with the **highest** gated median |
| Heatmap key text | `--heatmap-key-fg` | Label + ms on **sampled** keys only |
| Accent (10%) | `--color-accent` | **Not used for any new Analytics chrome.** Focus ring on the new nav button is the existing reserved mechanism. |
| Destructive | `--color-destructive` | **Not used.** No destructive action this phase. |

### New token values (locked — 06-RESEARCH.md Open Question 1)

Relative sequential **amber**, never RdYlGn, never `--color-accent` / `--color-destructive` (Pitfall 9, 03-UI-SPEC no score coloring). Scale against the min/max median of keys that **clear the 5-sample gate** in the current history (D-14). If fewer than two distinct gated medians, every sampled key uses `t = 0.5`.

```css
:root {
  --heatmap-lo: #fef3c7;   /* amber-100 */
  --heatmap-hi: #c97116;   /* locked for ≥4.5:1 vs --heatmap-key-fg and ≥3:1 vs lo */
  --heatmap-key-fg: #1c1c1a; /* == --color-text light */
}

@media (prefers-color-scheme: dark) {
  :root {
    --heatmap-lo: #2a1c08;
    --heatmap-hi: #9a5a14;
    --heatmap-key-fg: #e6edf3; /* == --color-text dark */
  }
}
```

Display-layer lerp (not in the analytics fold):

```
t = (hi === lo) ? 0.5 : (medianMs - lo) / (hi - lo)
background = mix(--heatmap-lo, --heatmap-hi, t)   /* sRGB channel lerp is acceptable */
```

**Contrast locks (both themes):**

- `--heatmap-key-fg` on `--heatmap-lo` **and** on `--heatmap-hi`: ≥ 4.5:1 (WCAG 1.4.3 AA for the on-key number).
- `--heatmap-lo` vs `--heatmap-hi` (endpoint pair): ≥ 3:1 so the scale reads as a range. Intermediate lerp neighbors are **not** required to hit 3:1 — D-12's on-key number is the non-color cue (WCAG 1.4.1 / G14).
- Unused / below-gate / `sampleable: false` keys: `background: var(--color-surface); color: var(--color-text)` — **never** a "fast" lo tint, **never** a number (D-13).

### Why the heatmap is not green/red

03/04/05-UI-SPEC forbid performance-threshold color-coding. A classic RdYlGn heatmap would paint "good" green and "bad" red and collide with `--color-accent` / `--color-destructive`. Sequential amber answers "where is latency higher *relative to this history*" — it is not a grade. Color is never the only cue: every sampled key shows its rounded median ms (D-12).

### Accent reserved for (unchanged from Phase 5 — no additions)

1. Primary buttons ("Load exercise", "Restart exercise") — unchanged.
2. The focus ring on every interactive element (now also the Analytics nav button) — unchanged mechanism.
3. The capture `<textarea>`'s border while focused — unchanged.
4. The custom trainer caret — unchanged.

Phase 6 adds no fifth entry. Heatmap tokens are **not** accent.

## Interaction Contract

**Everything below is additive to `01–05-UI-SPEC.md` (theme, focus-ring, 150ms motion cap, no-layout-shift, hide-don't-unmount, display-layer rounding). Those rules still apply.**

- **View toggle:** three native `<button>`s. Click / Enter / Space. Focus stays on the activated button — do not move focus into the dashboard or back into the trainer `<textarea>`.
- **Hide, don't unmount:** trainer visibility is inline `display: grid | none` — not the `hidden` attribute, not `{view === 'trainer' && …}`.
- **No in-page navigation:** no skip-to-section links, hash routes, or sticky section index (D-03).
- **Tables and heatmap keys are inert:** no `onClick`, no `href`, no `tabindex`, no pointer-cursor, no hover elevation, no sort-on-header-click. Heatmap keys are `<div>`s (or equivalent), **not** `<button>`s. Accessible names via `aria-label` as specified in Copywriting. The figure wrapper is `role="group"` with `aria-label="US ANSI keyboard, median latency in milliseconds"`.
- **Motion:** view switch is an **instant** swap — no slide, fade, or cross-dissolve. No row-entry animation, no heatmap color transition, no count-up. If any opacity is used on the dashboard itself, it must reuse the existing 150ms cap inside `@media (prefers-reduced-motion: no-preference)` — default is **no** new motion.
- **No layout shift:** three nav labels render from first paint. Sections do not pop in after a loading flash on subsequent live-query updates (see backstop).
- **Rounding discipline:** `Math.round()` only in `DigraphLatencyView` / `KeyboardHeatmap` / `LanguageProfileView`. Never inside `analytics.ts`, `heatmap.ts`, or `latency-stats.ts`.
- **`role="status"`** on the dashboard wrapper (polite), matching History / Results. Do not use `role="alert"`.
- **Security (ASVS V5):** untrusted persisted strings (digraph pair, `exercise.language`, key `label`) are text nodes only.
